# RO 段落排序 Re-order Paragraphs

← 返回 [阅读](../README.md) · [总目录](../../README.md)

## 题型速览

- 给出打乱顺序的几段文字，拖动排成正确顺序。
- 评分：每对相邻顺序正确得 1 分。计入**阅读**。

## 基本模板

1. **找首句：** 能独立成立、引出话题，没有 he / it / this / however 这类承接词。
2. **找配对：** 代词指代（this method → 前面提到的 method）、连接词（however, therefore）、时间顺序。
3. **先确定能确定的两两相邻**，再拼成整体。

## 技巧

- 定冠词 the + 前文出现过的名词，说明它不在开头。
- 按"两两成对"得分，即使全文排不对，也要保证有把握的那几对相邻。
