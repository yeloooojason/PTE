# MCMA 阅读多选 Multiple Choice, Multiple Answers

← 返回 [阅读](../README.md) · [总目录](../../README.md)

## 题型速览

- 读一段文字，问题有不止一个正确答案。
- 评分：选对一个 +1，选错一个 −1，最低 0 分。计入**阅读**。

## 基本模板

1. **先读题干**，划出关键词。
2. **回原文定位**，逐个核对选项。
3. **只选有原文依据的**，通常选 1～2 个。

## 技巧

- 性价比低，时间紧时快速选一个最有把握的就走。
- 绝对化的词（always / never / all）多半是错的。
