# RFIB 阅读填空 Reading: Fill in the Blanks

← 返回 [阅读](../README.md) · [总目录](../../README.md)

## 题型速览

- 一篇短文里有若干空，从下面的词库里拖词进去（词比空多）。
- 评分：每空答对 1 分，不倒扣。计入**阅读**。

## 基本模板

1. **先把词库按词性分类**（名词/动词/形容词/副词）。
2. **每个空判断词性**，缩小范围。
3. **最后用搭配和意思确定**，先填最有把握的。

## 技巧

- 每个词只能用一次，填完一个就排除一个。
- 所有空都要填满。
