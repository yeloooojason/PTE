# MCSA 阅读单选 Multiple Choice, Single Answer

← 返回 [阅读](../README.md) · [总目录](../../README.md)

## 题型速览

- 读一段文字，选一个正确答案。
- 评分：对 1 分，错 0 分，不倒扣。计入**阅读**。

## 基本模板

1. **先读题干**，看问的是主旨、细节还是推断。
2. **回原文定位**，排除与原文矛盾或原文没提的选项。
3. **剩下的选最贴近原文意思的。**

## 技巧

- 分值低，不要花太多时间，一定要选一个。
