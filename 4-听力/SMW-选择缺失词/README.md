# SMW 选择缺失词 Select Missing Word

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 录音最后一个词或几个词被"哔"声代替，选出缺失的内容。
- 评分：对 1 分，错 0 分。计入**听力**。

## 基本模板

1. **录音前看选项**，知道大概主题。
2. **听最后几句的逻辑**：是转折、因果还是总结。
3. **选**最符合上文逻辑的那个。

## 技巧

- 注意录音结尾的语气和关键词，答案常和开头提出的话题呼应。
