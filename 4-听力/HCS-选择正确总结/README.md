# HCS 选择正确总结 Highlight Correct Summary

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一段录音，从几段总结中选出最准确的一段。
- 评分：对 1 分，错 0 分。计入**听力**和**阅读**。

## 基本模板

1. **边听边记主旨和几个要点。**
2. **排除**：有录音没提到的细节、有和录音矛盾的、只说了一部分的。
3. **选**覆盖主旨又没有错误信息的那段。

## 技巧

- 选项较长，可以先听再读，避免分心。
