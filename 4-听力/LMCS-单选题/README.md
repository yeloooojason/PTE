# LMCS 听力单选 Multiple Choice, Single Answer

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一段录音，选一个正确答案。
- 评分：对 1 分，错 0 分。计入**听力**。

## 基本模板

1. **录音前读题干**，知道要听什么。
2. **边听边排除**，选最贴近录音意思的。

## 技巧

- 一定要选一个，不倒扣。
