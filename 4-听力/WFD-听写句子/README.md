# WFD 听写句子 Write From Dictation

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一个 3～5 秒的句子，只播一次，把整句打出来。
- 评分：每个拼写正确的词得 1 分。计入**听力**和**写作**，分值很高。

## 基本模板

1. **听的时候按意群记**，可以只打每个词的首字母先占位。
2. **录音结束后马上补全**整句。
3. **检查**：单复数、时态、冠词、拼写、句首大写和句号。

## 技巧

- 这是听力最值钱的题，每天练。
- 这类题短，可以**按日期一个文件**记一批错的句子。
