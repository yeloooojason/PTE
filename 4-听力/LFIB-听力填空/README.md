# LFIB 听力填空 Fill in the Blanks

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 屏幕上是录音的文字稿，有几个空，边听边把听到的词打进去。
- 评分：每空拼写正确得 1 分。计入**听力**和**写作**。

## 基本模板

1. **录音前快速扫一遍文本**，看空前后的词。
2. **听到就先打前几个字母**，录音结束后再补全。
3. **检查拼写和单复数、时态**（-s / -ed）。

## 技巧

- 拼错不得分，平时多练常见学术词的拼写。
