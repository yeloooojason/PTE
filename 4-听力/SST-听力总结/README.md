# SST 听力总结 Summarize Spoken Text

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一段 60～90 秒的讲座，10 分钟内写 50～70 词的总结。
- 评分：内容、形式（字数）、语法、词汇、拼写。计入**听力**和**写作**。

## 基本模板

1. The speaker discussed **[主题]**.
2. First, **[要点 1]**.
3. Second, **[要点 2]**. Furthermore, **[要点 3 / 例子]**.
4. In conclusion, **[结论 / 讲者的态度]**.

## 技巧

- 边听边记名词、数字、转折词后面的内容。
- 字数控制在 55～65 词，写完检查拼写。
- 用听到的原词更安全，不确定拼写就换简单词。
