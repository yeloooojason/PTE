# HIW 找错词 Highlight Incorrect Words

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 屏幕上是文字稿，录音和文字有几个词不一样，点出这些词。
- 评分：点对一个 +1，点错一个 −1，最低 0 分。计入**听力**和**阅读**。

## 基本模板

1. **录音开始时用鼠标指着第一个词**，跟着录音逐词移动。
2. **听到不一样的立刻点**，不要回头。
3. **没把握不要点**，点错会扣分。

## 技巧

- 错词常常是形近词或意思相近的词，耳朵跟紧、眼睛别跳行。
