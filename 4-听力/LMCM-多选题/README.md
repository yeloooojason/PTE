# LMCM 听力多选 Multiple Choice, Multiple Answers

← 返回 [听力](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一段录音，选多个正确答案。
- 评分：选对一个 +1，选错一个 −1，最低 0 分。计入**听力**。

## 基本模板

1. **录音开始前先读题干和选项**，划关键词。
2. **边听边排除**明显没提到的选项。
3. **只选有把握的**，通常 1～2 个。

## 技巧

- 性价比低，不要在这题上纠结太久。
