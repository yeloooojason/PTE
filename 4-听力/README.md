# 听力 Listening

← 返回 [总目录](../README.md)

音频只播一次。边听边记关键词；多选和找错词题选错会扣分。

点进题型文件夹，首页就是这个题型的基本模板和技巧，练过的题放在同一个文件夹里。

| 题型 | 名称 |
|---|---|
| [SST](SST-听力总结/) | 听力总结 Summarize Spoken Text |
| [LMCM](LMCM-多选题/) | 听力多选 Multiple Choice, Multiple Answers |
| [LFIB](LFIB-听力填空/) | 听力填空 Fill in the Blanks |
| [HCS](HCS-选择正确总结/) | 选择正确总结 Highlight Correct Summary |
| [LMCS](LMCS-单选题/) | 听力单选 Multiple Choice, Single Answer |
| [SMW](SMW-选择缺失词/) | 选择缺失词 Select Missing Word |
| [HIW](HIW-找错词/) | 找错词 Highlight Incorrect Words |
| [WFD](WFD-听写句子/) | 听写句子 Write From Dictation |
