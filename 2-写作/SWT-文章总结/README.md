# SWT 文章总结 Summarize Written Text

← 返回 [写作](../README.md) · [总目录](../../README.md)

## 题型速览

- 读一篇最长约 300 词的文章，10 分钟内写**一句话**总结，5～75 词。
- 评分：内容、形式（必须一句话、字数达标）、语法、词汇。计入**写作**和**阅读**。

## 基本模板

1. The passage discusses **[主题]**, explaining that **[要点 1]** and **[要点 2]**, which suggests that **[结论]**.
2. 或：While **[对立观点/背景]**, the author argues that **[主要观点]** because **[原因]**, and therefore **[结论]**.

## 技巧

- 只能有一个句号；用 and / which / while / because 把要点连起来。
- 每段找一个主旨句，摘取关键词改写成要点。
- 目标 30～50 词，写完检查：只有一个句号、主谓一致、拼写。
