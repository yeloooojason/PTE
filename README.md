## 怎么加新题

1. 进对应的题型文件夹（DI 再进对应图类文件夹）。
2. 把 [_模板/新题模板.md](_模板/新题模板.md) 复制进来，按顺序编号命名：`01-关键词.md`、`02-关键词.md`……题目图片放在同一个文件夹。
3. 填题目、我的答案、参考答案、要点，用不到的部分删掉。
4. 在该文件夹 `README.md` 底部的"练过的题"表格加一行。
5. 在 [practice-log.md](practice-log.md) 的"每日练习"加一行。

RS、ASQ、WFD 这种一题很短的题型，可以按日期一个文件记一批（如 `2026-11-02.md`），不用一题一个文件。

## 怎么加新题型

在对应模块下新建 `缩写-中文名/` 文件夹，复制同模块任意一个题型的 `README.md` 进去改内容，再到模块的 `README.md` 和本页目录各加一行。
