# 口语 Speaking

← 返回 [总目录](../README.md)

开口类题目，全部按内容、流利度、发音评分。流利度最重要：不要停顿、不要回头改。

点进题型文件夹，首页就是这个题型的基本模板和技巧，练过的题放在同一个文件夹里。

| 题型 | 名称 |
|---|---|
| [RA](RA-朗读/) | 朗读 Read Aloud |
| [RS](RS-复述句子/) | 复述句子 Repeat Sentence |
| [DI](DI-看图描述/) | 看图描述 Describe Image（按图类分子文件夹） |
| [RL](RL-复述讲座/) | 复述讲座 Re-tell Lecture |
| [ASQ](ASQ-简短回答/) | 简短回答 Answer Short Question |
| [SGD](SGD-小组讨论总结/) | 小组讨论总结 Summarize Group Discussion |
| [RTS](RTS-情景回应/) | 情景回应 Respond to a Situation |
