# RTS 情景回应 Respond to a Situation

← 返回 [口语](../README.md) · [总目录](../../README.md)

## 题型速览

- 2025 年新增题型。阅读（同时会听到）一个生活或学习场景，准备约 20 秒，录音约 40 秒，像打电话或当面说话一样回应。
- 评分：内容是否得体切题、流利度、发音。计入**口语**。（具体时长以 Pearson 官方最新说明为准）

## 基本模板

1. Hi **[对方：Professor Smith / Tom]**, this is **[你的名字/身份]**.
2. I'm calling about **[事情]**. Unfortunately, **[问题 / 原因]**.
3. I'm really sorry about **[道歉，如果需要]**.
4. Would it be possible to **[请求 / 方案 1]**? Alternatively, I could **[方案 2]**.
5. Thank you for your understanding. I look forward to hearing from you.

## 技巧

- 按"称呼 → 说明情况 → 原因 → 方案/请求 → 感谢"五步，场景里的每个要点都要回应到。
- 语气礼貌：Would it be possible…? / Could you please…? / I was wondering if…
- 对象是老师、上司时用正式语气，对朋友可以轻松一点。
