# RA 朗读 Read Aloud

← 返回 [口语](../README.md) · [总目录](../../README.md)

## 题型速览

- 屏幕上一段文字（最多约 60 词），准备 30～40 秒，然后读出来，录音时间和准备时间差不多。
- 评分：内容、流利度、发音。计入**口语**和**阅读**。
- 提示音后 3 秒不开口，或中途停顿超过 3 秒，录音会自动结束。

## 基本模板

1. **准备的 30 秒：** 用眼睛按意群断句（一般在逗号、介词、that/which、and/but 前停），找出长单词和难读的数字。
2. **开读：** 提示音后马上开口，按意群一口气读完一组，组与组之间短停。
3. **读错了：** 不要回头重读，直接往下读。

## 技巧

- 语速均匀，像新闻播报，不要越读越快。
- 句号处停得比逗号稍长，句末语调下降。
- 不认识的词按拼写大胆读，不要停下来。
- 数字、年份、缩写提前想好读法（2019 → twenty nineteen）。
