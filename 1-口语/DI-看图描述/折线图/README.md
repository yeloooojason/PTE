# 折线图 Line Graph 模板

← 返回 [DI 总览](../README.md)

## 基本模板

1. This line chart shows **[题目]**.
2. The highest is at **[X]**, at about **[数字]**.
3. The lowest is at **[Y]**, only about **[数字]**.
4. **[It / 线名]** rises until **[X]**, and then falls.
5. Overall, **[A 线]** is higher than **[B 线]** at every point.

## 要点

题目直接照抄图上的标题；数字带上单位（如 dollars / percent / million）。第 4 句是折线图最重要的趋势句，按图换词：一直上升用 keeps rising，一直下降用 keeps falling，先降后升用 falls until [X], and then rises。只有一条线时，第 5 句改成 Overall, it [rises / falls] from [数字] to [数字]。
