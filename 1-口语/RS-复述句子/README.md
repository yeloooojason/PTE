# RS 复述句子 Repeat Sentence

← 返回 [口语](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一个 3～9 秒的句子，只播一次，听完立刻复述，录音约 15 秒。
- 评分：内容（按顺序说对的词）、流利度、发音。计入**口语**和**听力**。

## 基本模板

1. **听的时候：** 按意群记（主语+动词 / 介词短语 / 从句），跟着说话人的节奏在心里默念。
2. **说的时候：** 提示音后马上开口，模仿原句的语调和停顿。
3. **没记全：** 把记住的部分流利地说出来，不要停、不要说 "sorry"。

## 技巧

- 流利度比一字不差更重要。
- 前半句通常记得最牢，先保证前半句完整。
- 这类题短，可以**按日期一个文件**记一批难句，不用一题一个文件。
