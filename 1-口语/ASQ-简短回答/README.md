# ASQ 简短回答 Answer Short Question

← 返回 [口语](../README.md) · [总目录](../../README.md)

## 题型速览

- 听一个 3～9 秒的问题（可能有图片），用一个词或几个词回答，录音约 10 秒。
- 评分：答对得分，答错 0 分。计入**口语**和**听力**。

## 基本模板

1. **听：** 抓住问句的疑问词（what / which / how many / who）。
2. **答：** 直接说答案，一个词或一个短语就够，例如 "A thermometer."
3. **不知道：** 也说一个最可能的词，不要沉默。

## 技巧

- 积累常识词：日历、形状、身体部位、职业、地理、科学、日常物品。
- 这类题短，可以**按日期一个文件**记一批不会的题。
