# 折线图 Line Graph 模板

**模板（4 步）**

1. **标题 + 横纵轴：** This line graph shows **[标题]**. The vertical axis shows **[纵轴内容+单位]**, and the horizontal axis shows **[横轴内容，如 the years from 1990 to 2020]**.
2. **最值：** The highest point is **[哪条线]**, at about **[数字]** in **[年]**, while the lowest is **[数字]** in **[年]**.
3. **再说一个数据：** In addition, **[另一条线/另一个时间点]** was about **[数字]** in **[年]**.
4. **总结：** Overall, **[整体趋势：rose / declined / fluctuated]**.

**要点：** 纵轴看单位（units / percent / million），横轴看起止年份；最值只说最高和最低；第 3 步挑一个最好读的数字就行；趋势词：rose / increased / fluctuated / remained stable / dropped / declined。
